# Floki Group

Прототип B2B-платформы для профессионалов мебельного рынка. Главная страница — четыре этапа сотрудничества от создания проекта до получения заказа.

## Запуск

Из `/workspace/floki`: `npm run dev` (Python 3, порт 3000). Зависимостей и сборки нет.

Стили встроены в HTML для просмотра отдельных файлов. Конструкторы и магазин фурнитуры — информационные страницы. Корзина и личный кабинет показывают пояснение; регистрация, расчёты, оплата и уведомления пока не подключены.

Этапы соединены SVG-дорожкой, заполняющейся при прокрутке. На мобильных экранах дорожка вертикальная. Учтена настройка уменьшения движения; без JavaScript карточки остаются видимыми.
